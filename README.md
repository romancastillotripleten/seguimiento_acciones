# 📦📈 Amazon Stock Dashboard (2020-2025)

> **"Transformando datos históricos en perspectivas estratégicas a través de la visualización interactiva."**

## 🚀 Acerca del Proyecto

Este proyecto es un panel de control interactivo (dashboard) diseñado para analizar el rendimiento financiero de las acciones de Amazon. Construido pensando en la usabilidad y el análisis ágil, la aplicación permite filtrar periodos específicos, evaluar el sentimiento del mercado y visualizar el impacto de eventos clave en el volumen de transacciones y el precio de cierre.

Es una pieza fundamental de portafolio que demuestra competencias clave en la manipulación de datos tabulares, diseño de interfaces de usuario para datos (Data Frontend) y creación de visualizaciones altamente responsivas.

## 🛠️ Tecnologías Utilizadas

Para garantizar un desarrollo ágil, código limpio y una experiencia de usuario sobresaliente, este proyecto se apoya en el siguiente stack tecnológico:

* **Python:** El motor principal para la lógica de programación y el procesamiento de datos.
* **Streamlit:** Framework de código abierto que permite transformar scripts de datos en aplicaciones web interactivas al instante.
* **Pandas:** La librería estándar de la industria para la limpieza, estructuración y manipulación de conjuntos de datos (DataFrames).
* **Plotly Express:** Herramienta de visualización avanzada que proporciona gráficos interactivos, estéticos y de alto rendimiento.

## 💻 Instrucciones de Instalación Local

Desplegar este proyecto en tu propia máquina es rápido y sencillo. Sigue estos pasos en tu terminal para comenzar a explorar los datos en menos de dos minutos.

1. **Clona el repositorio** para descargar el código fuente y los datos a tu equipo local:
```bash
git clone https://github.com/tu-usuario/amazon-stock-dashboard.git

```


2. **Navega al directorio** raíz del proyecto recién clonado:
```bash
cd amazon-stock-dashboard

```


3. **Instala las dependencias** necesarias para que el entorno funcione correctamente. Es una buena práctica usar un entorno virtual, pero en cualquier caso, ejecuta:
```bash
pip install -r requirements.txt

```


4. **Inicia la aplicación** levantando el servidor local de Streamlit:
```bash
streamlit run app.py

```



Una vez ejecutado el último comando, Streamlit compilará el código y abrirá automáticamente una nueva pestaña en tu navegador predeterminado (usualmente en `http://localhost:8501`) mostrando el dashboard en todo su esplendor. ¡Explora el código, ajusta los filtros y lleva tu análisis de datos al siguiente nivel!
